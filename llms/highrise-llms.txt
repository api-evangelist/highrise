# Highrise

> Highrise (Pocket Worlds Inc) is a mobile-first virtual world where users create avatars, hang out in social rooms, design and trade fashion items, and build custom worlds. Its developer platform exposes a WebSocket Bot API, a read-only REST Web API, and Highrise Studio (Lua Engine + Cloud API) for world building.

## APIs
- [Highrise Bot API](https://create.highrise.game/learn/guides/bots/creating-a-bot): WebSocket bots inside rooms (wss://highrise.game/web/botapi). Official Python and .NET SDKs.
- [Highrise Web API](https://create.highrise.game/learn): Read-only REST for public users, rooms, posts, items, grabs (https://webapi.highrise.game).
- [Highrise Studio](https://create.highrise.game): Engine API + Cloud API, Lua scripting for worlds and games.

## Specs
- [Web API OpenAPI](openapi/highrise-web-api-openapi.yml): Generated from the official SDK web-api client.
- [Bot API AsyncAPI](asyncapi/highrise-bot-api-asyncapi.yml): Bot event surface (chat, emote, joins, tips, voice, DMs, moderation).
